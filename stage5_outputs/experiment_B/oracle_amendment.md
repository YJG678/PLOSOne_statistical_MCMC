# Experiment B independent-oracle amendment

Amendment date: 2026-08-10  
Reason: the original candidate oracle was estimated from the same 1,280 paths
later partitioned into decision replicates.  All original Experiment B
selection frequencies are withdrawn.

## Frozen repair before the new streams

- Target settings, candidates, initialization, estimands, proposal scales,
  temperatures, and certification rule are unchanged.  Path horizon is now
  algorithm-specific solely to impose common target-evaluation work.
- Every candidate receives exactly 3,000 target-density evaluations per path.
  Local RWM and transport independence therefore use 3,000 sweeps; the
  five-rung parallel-tempering candidate uses 600 sweeps.  Swap decisions use
  cached target values and add no target evaluation.  Proposal-density
  calculations and temperature-swap overhead remain visible in wall time.
- The earlier equal-600-sweep comparison is withdrawn as an efficiency
  comparison because it gave parallel tempering five times the target work.
- Candidate risk for the primary mode-probability estimand is estimated from
  two independent 10,000-path oracle batches per candidate and setting.
- The oracle is resolved only if both batch winners equal the combined winner
  and the combined best--second gap is at least five Monte Carlo standard
  errors.  Otherwise the setting is reported as oracle-ambiguous and no
  selection-error frequency is computed.
- The decision stream contains 100 disjoint 223-path units per setting (300
  units overall), independently generated after the repair was frozen.
- Every unit applies exactly twelve Gate-2 tests: mode entry and exit and
  scientific-event entry and exit for each of the three candidates.  Each test
  uses a one-sided Clopper--Pearson upper bound with error `1/1200`; hence the
  twelve-test familywise error is `.01`.  The frozen threshold is
  `z_max=.10`, and all four directional tests must pass for a candidate to be
  eligible.
- The certification stream contains a further 551 paths per candidate and
  setting.
- Base seeds are 326000001 (matched-work oracle), 325000001
  (matched-work protocol-aligned decision), and 327000001 (matched-work
  certification), expanded by setting, candidate, and batch indices with
  NumPy `SeedSequence`.

The oracle size was chosen from the scale of the withdrawn exploratory risk
gaps.  No path from the equal-sweep study is reused.  The new matched-work
oracle, decision, and certification streams are mutually disjoint.

## Resolution outcome

Both oracle batches and their combination identify transport independence in
all three settings.  The combined best--second gaps are 73.98, 60.22, and
20.11 Monte Carlo standard errors in B1--B3.  Therefore all three settings
satisfy the prespecified resolution rule.  All 300 matched-work decision units
select that independently resolved oracle; there are no false selections,
aborts, or oracle exclusions.  The false-selection contrast from the
equal-sweep run is withdrawn.

Authoritative outputs are `oracle_risk.csv`, `oracle_resolution.csv`,
`selection_repetitions.csv`, `gate2_tests.csv`, `certification.csv`,
`stream_manifest.csv`, `work_accounting.csv`, `work_summary.csv`, and
`summary.json`, generated by `stage5_mixture.py`.
